# Video packs

Built from runs 39581314026 (uz) and 39583434375 (ru, en) by collect-video-packs.yml.

- video/: all pack files and manifest.json (upload as-is to the video server)
- zips: run python3 tools/video/zip_packs.py video zips for one zip per pack
- app/: web/video/index.js and the topic 1 videos shipped in the APK
