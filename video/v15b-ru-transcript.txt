Метод Фурье: струна и стержень

[0:00] Гитарная струна закреплена с обоих концов, поэтому волны отражаются, и формула Даламбера напрямую не работает. Метод Фурье предлагает другой путь: строить решение как сумму простых «мод». В этой части изучим этот метод для струны и для стержня.

[0:20] Ищем решение в виде большое X от x на большое T от t. После подстановки часть, зависящая от x, равна части, зависящей от t; это возможно, только если обе равны одной постоянной минус лямбда. Задача для X: X два штриха плюс лямбда X равно нулю, X в нуле и X в l равны нулю.

[0:45] Если лямбда отрицательна или равна нулю, получается только нулевое решение. Если лямбда положительна, X равно синусу корня из лямбда на x, и синус корня из лямбда на l должен быть равен нулю. Значит, собственные значения лямбда n равны квадрату n пи делённого на l, собственные функции — синус n пи x делённое на l, n равно один, два, три и так далее.

[1:16] Пример: u t t равно u x x, x от нуля до пи, концы закреплены. Начальная форма два синус x минус синус три x, начальная скорость четыре синус два x. Здесь моды — синус n x на косинус n t или синус n t.

[1:36] Данные уже являются суммой синусов, поэтому интегралы не нужны. При t равном нулю сравниваем: A один равно двум, A три равно минус единице. В скорости стоит n на B n: два B два равно четырём, B два равно двум. Ответ: два синус x косинус t плюс два синус два x синус два t минус синус три x косинус три t.

[2:03] Для теплопроводности в стержне задача для X та же, но T теперь удовлетворяет уравнению первого порядка и экспоненциально затухает. Например, если начальная температура пять синус пи x плюс два синус три пи x, решение — пять e в степени минус пи квадрат t синус пи x плюс два e в степени минус девять пи квадрат t синус три пи x.

[2:30] На графике профиль температуры в три момента: t равно нулю, одной сотой и пяти сотым. Третья мода затухает в девять раз быстрее, поэтому профиль быстро превращается в одну простую дугу и затем медленно опускается. У струны же моды не затухают, а колеблются.

[2:52] Вопрос: как меняется во времени n-я мода в стержне длины l с нулевой температурой на концах? Обратите внимание на квадрат в показателе.
