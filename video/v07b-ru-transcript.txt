Вронскиан и фундаментальная система решений

[0:00] Чтобы построить общее решение из двух решений, они должны быть линейно независимы. Удобный инструмент проверки — определитель Вронского. Но с ним нужна осторожность: выводы для произвольных функций и для решений уравнения различаются.

[0:19] Вронскиан двух функций: игрек один на игрек два штрих минус игрек один штрих на игрек два. Если функции линейно зависимы на интервале, вронскиан там тождественно равен нулю. Значит, если хоть в одной точке вронскиан не равен нулю, функции обязательно независимы. Например, для e в степени икс, e в степени два икс и e в степени три икс вронскиан равен два e в степени шесть икс.

[0:49] Теперь предостерегающий пример: икс квадрат и икс, умноженный на модуль икс, на интервале от минус одного до одного. При положительном икс обе функции равны икс квадрат, при отрицательном вторая равна минус икс квадрат. В обоих случаях вронскиан равен нулю. Значит, вронскиан тождественно нуль.

[1:16] Но зависимы ли они? Пусть альфа один икс квадрат плюс альфа два икс модуль икс тождественно равно нулю. При икс равном половине: альфа один плюс альфа два равно нулю; при икс равном минус половине: альфа один минус альфа два равно нулю. Значит, обе альфы равны нулю — функции независимы! Вывод: для произвольных функций равенство вронскиана нулю не означает зависимости.

[1:45] Для решений ситуация другая. Если игрек один и игрек два — решения одного линейного однородного уравнения с непрерывными коэффициентами, вронскиан либо всюду равен нулю, либо нигде. Это показывает формула Остроградского–Лиувилля: W равно W в начальной точке, умноженному на e в степени минус интеграл от p, а экспонента никогда не равна нулю.

[2:15] На графике показаны икс квадрат и икс модуль икс. Справа они совпадают, а слева зеркально противоположны. Ни один постоянный множитель не подходит сразу для обеих сторон — поэтому функции независимы.

[2:32] n линейно независимых решений уравнения n-го порядка называются фундаментальной системой. Любое решение однородного уравнения — их линейная комбинация. Общее решение неоднородного уравнения — эта комбинация плюс одно частное решение. Например, для игрек два штриха плюс игрек равно икс: C один косинус икс плюс C два синус икс плюс икс.
