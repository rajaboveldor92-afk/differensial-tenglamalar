Уравнение n-го порядка и уравнения без y или без x

[0:00] Здравствуйте! Переходим к уравнениям высших порядков. Когда телефон падает с высоты, его высота удовлетворяет уравнению: вторая производная равна минус g. Посмотрим, как решать такие уравнения и когда можно понизить их порядок.

[0:19] Общее решение уравнения n-го порядка содержит n произвольных постоянных. В задаче Коши в одной точке задаются n условий: функция и её производные до порядка n минус один. Если правая часть непрерывна и её частные производные по неизвестным непрерывны, решение локально существует и единственно.

[0:44] Первый тип: n-я производная зависит только от x. Например, игрек трижды штрих равно двадцать четыре икс, начальные значения один, ноль и два. Интегрируем и каждый раз сразу находим постоянную: игрек два штриха равно двенадцать икс квадрат плюс два, игрек штрих равно четыре икс в кубе плюс два икс, и игрек равно икс в четвёртой плюс икс квадрат плюс один.

[1:13] Второй тип: уравнение без y. Например, икс игрек два штриха минус игрек штрих равно три икс квадрат. Положив z равно игрек штрих, получаем линейное уравнение первого порядка для z. Деля на икс квадрат, видим: производная от z, делённого на икс, равна трём. Значит z равно три икс квадрат плюс C один икс, а игрек равно икс в кубе плюс половина C один икс квадрат плюс C два.

[1:47] Третий тип: уравнение без x, например игрек два штриха равно два игрек в кубе. Полагаем игрек штрих равно p, где p — функция от игрек. По цепному правилу игрек два штриха равно p, умноженному на dp по dy. Важно: не просто dp по dy! Интегрируя, получаем p квадрат равно игрек в четвёртой плюс C один.

[2:16] Пусть начальные условия: игрек в нуле равно одному, игрек штрих в нуле равно одному. Тогда C один равно нулю и p равно игрек квадрат. Разделяя переменные, получаем минус один делить на игрек равно икс минус один, то есть игрек равно единице, делённой на один минус икс. Решение существует только при икс меньше одного: при приближении икс к единице оно уходит в бесконечность.

[2:48] На графике показана функция игрек равно единице, делённой на один минус икс. В нуле она равна единице, и наклон тоже равен единице. При приближении икс к единице кривая круто уходит вверх к вертикальной асимптоте. Для нелинейных уравнений такой взрыв — обычное явление.
