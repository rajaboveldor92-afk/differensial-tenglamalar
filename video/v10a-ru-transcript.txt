Вариация постоянных

[0:00] Метод прошлого урока работал только для экспоненты, многочлена, синуса и косинуса. А если правая часть — единица, делённая на косинус икс, или тангенс икс? Сегодня изучаем универсальный метод — вариацию постоянных. Он работает для любой непрерывной правой части и даже для переменных коэффициентов.

[0:25] Идея: превращаем постоянные в однородном решении це один игрек один плюс це два игрек два в функции от икс. Для двух неизвестных функций ставим два условия. Первое: це один штрих игрек один плюс це два штрих игрек два равно нулю. Второе следует из уравнения: це один штрих игрек один штрих плюс це два штрих игрек два штрих равно эф.

[0:53] Определитель этой системы — вронскиан, он не равен нулю. По правилу Крамера: це один штрих равно минус игрек два эф, делённое на дубль-вэ, це два штрих равно игрек один эф, делённое на дубль-вэ. Важное предупреждение: формулы верны, только когда коэффициент при игрек два штриха равен единице. Иначе сначала разделите на него уравнение.

[1:21] Пример: игрек два штриха плюс игрек равно единице, делённой на косинус икс, на интервале от минус пи пополам до пи пополам. Однородные решения — косинус икс и синус икс, вронскиан — косинус квадрат плюс синус квадрат, то есть единица. Очень удобно.

[1:44] Це один штрих равно минус синус икс, делённый на косинус икс, интеграл — натуральный логарифм косинуса икс; на этом интервале косинус положителен. Це два штрих равно косинусу, делённому на косинус, то есть единице, интеграл — икс. Частное решение: косинус икс на логарифм косинуса икс плюс икс синус икс.

[2:11] Почему важно приведение? Возьмём уравнение икс квадрат игрек два штриха минус два икс игрек штрих плюс два игрек равно икс кубу. Разделив на икс квадрат, получаем эф равно икс, а не икс куб. Верный расчёт даёт икс куб пополам. Если забыть деление, получится икс в пятой степени, делённый на двенадцать, и это не решение.

[2:40] На графике показано частное решение косинус икс на логарифм косинуса икс плюс икс синус икс. Когда икс приближается к пи пополам, сила неограниченно растёт, но само решение остаётся ограниченным. Решение существует только на интервале, содержащем начальную точку, то есть от минус пи пополам до пи пополам.

[3:04] Вопрос: чему равно це два штрих для игрек два штриха плюс игрек равно тангенсу икс? Вспомните, что игрек один — косинус икс, а вронскиан равен единице, и подставьте в формулу. Остановите видео и выберите ответ.
