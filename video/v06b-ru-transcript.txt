Однородные и обобщённо однородные уравнения

[0:00] В этой части рассмотрим ещё два типа уравнений. В первом при умножении y и всех её производных на одно число уравнение не меняется. Во втором мы приписываем x и y разные «веса» и уравниваем все члены. В обоих случаях порядок понижается на единицу.

[0:22] Если уравнение однородно относительно игрек, игрек штрих, игрек два штриха, делаем замену: игрек штрих равно игрек, умноженному на z. Тогда игрек два штриха равно игрек, умноженному на z штрих плюс z квадрат. После сокращения на степень игрек остаётся уравнение первого порядка для z. Внимание: это ещё один смысл слова «однородное».

[0:53] Пример: икс игрек игрек два штриха минус икс квадрат игрек штрих равно игрек игрек штрих. Каждый член второй степени по игрек. После замены сокращаем на игрек квадрат и получаем: икс z штрих равно z. Значит z равно C один икс.

[1:14] Теперь игрек штрих, делённое на игрек, равно C один икс. Интегрируя, получаем игрек равно C два, умноженное на e в степени половина C один икс квадрат. При C два равном нулю тождественный ноль тоже решение. Результат легко проверить подстановкой.

[1:37] Теперь припишем x вес один, а y вес m. Тогда вес игрек штрих равен m минус один, игрек два штриха — m минус два. В уравнении икс в кубе игрек два штриха равно квадрату икс игрек штрих минус игрек получаем m плюс один равно два m, то есть m равно одному. Замена икс равно e в степени t, игрек равно e в степени t, умноженное на u, убирает t.

[2:07] В последнем уравнении нет ни t, ни u, поэтому полагаем q равно производной u и получаем уравнение с разделяющимися переменными. Ответ: игрек равно икс логарифм икс минус икс логарифм модуля один минус C один икс плюс C два икс. Кроме того, случай q равно нулю даёт решения игрек равно C икс — их нужно выписать отдельно.

[2:34] На графике показаны кривые игрек равно e в степени половина C один икс квадрат из первого примера при трёх значениях C один. При положительном C один кривая растёт, при отрицательном — затухает колоколом, при нулевом — горизонтальная прямая.

[2:54] Проверьте себя: какая замена подходит для уравнения, однородного относительно игрек, игрек штрих, игрек два штриха? Выберите ответ.
