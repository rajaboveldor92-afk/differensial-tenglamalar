Линейный оператор, суперпозиция и интервал существования

[0:00] Здравствуйте! Если в электрической цепи без внешнего источника возможны два режима колебаний, то их сумма тоже возможный режим. Это главное свойство линейных уравнений — суперпозиция. Сегодня мы дадим ему точную формулировку и научимся находить интервал существования решения.

[0:24] Запишем линейное уравнение в виде L от игрек равно f, где L — сумма n-й производной и младших производных с коэффициентами, зависящими от x. Оператор L линеен: на комбинацию двух функций он действует как та же комбинация результатов. При f равном нулю уравнение называется однородным — это другой смысл слова «однородное».

[0:52] Пример: икс квадрат игрек два штриха минус два игрек равно нулю, икс положителен. Икс квадрат — решение: два икс квадрат минус два икс квадрат равно нулю. Единица, делённая на икс, тоже решение: икс квадрат, умноженный на два, делённое на икс в кубе, минус два, делённое на икс, равно нулю. По суперпозиции C один икс квадрат плюс C два, делённое на икс, тоже решение.

[1:24] Теперь зададим условия: игрек в единице равно одному, игрек штрих в единице равно пяти. C один плюс C два равно одному, два C один минус C два равно пяти. Складывая, три C один равно шести, значит C один равно двум, C два — минус одному. Ответ: игрек равно два икс квадрат минус единица, делённая на икс. Определитель системы равен минус трём — это значение вронскиана.

[1:56] Важный результат для линейного уравнения: если коэффициенты и правая часть непрерывны на интервале, решение задачи Коши существует и единственно на всём этом интервале. Поэтому сначала делим на старший коэффициент и находим точки разрыва. Например, если перед игрек два штриха стоит икс квадрат минус четыре, опасные точки — икс равно двум и минус двум.

[2:26] На графике показаны два фундаментальных решения — икс квадрат и единица, делённая на икс, — и найденное решение два икс квадрат минус единица, делённая на икс. Третья кривая — линейная комбинация первых двух, в точке икс равно один её значение один, а наклон пять.

[2:48] Проверьте себя: для каких уравнений верна суперпозиция? Выберите ответ и прочитайте пояснение.
